Bubble Breaker: screens (layout 1b)
Every frame is live. Tap a group to select it and tap it again to burst it. Click a board and use the arrow keys, Enter and Esc to try the keyboard. The Menu opens the other screens. See also the Component Sheet, the Handoff and Turn 1.

C · PWA notices and the Greyscale set
Notices appear at the top of the board area. The board is anchored to the bottom, so there is always free space above it on a portrait phone and notices never cover balls. Install is offered once, after the first finished game, and never on the first visit.

D · Other sizes
The cell size is computed from both viewport dimensions and the chrome stays at fixed pixel sizes. Phones are width-limited and the spare height sits above the board. The tablet fills almost the whole screen. On desktop the game is a centered app window sized to the board's 11:12 aspect, with the cell capped at 48px. A stretched full-window layout would leave the board floating in empty width and would lose the chrome that gives the game its character. A fake phone bezel would suggest touch-only input.
