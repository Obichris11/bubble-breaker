Turn 1: Game screen, two layouts
Both run at 360×640 with identical ball rendering and are playable: tap a group to highlight it, then tap it again to burst it. Only the score and time placement differs. The board is anchored to the bottom, just above the softkeys. Balls fall downward, so the fixed floor stays in thumb reach while cleared space opens up above.
