# Plan 06 — PWA Implementation Plan

> **For agentic workers:** run **one implementer subagent per task**, in order, and review each task's diff and test output before starting the next (the superpowers plugin does not load in cloud sessions; see the roadmap's working agreement). Steps use checkbox (`- [ ]`) syntax for tracking. Task 8 is a **browser check** with Playwright against a production build served with its service worker. Open the PR and poll its checks with the **GitHub connector** (`gh` has no token in cloud sessions). **Do not merge**: the user merges.

**Goal:** Make the game an installable, offline PWA. A web app manifest and icons; the Angular service worker with asset groups only; a `PwaPort` in `platform` (with a fake) that reports a downloaded update, a finished first cache, a kept install prompt and an unrecoverable worker; a `PwaStore` in `state` that picks one notice at a time and saves the game before any reload; and the three notices from 02-ux at the top of the board area (New version → Reload, Offline ready → auto-hide 4 s, Install → after the first finished game, "Not now" for 30 days). CI's `build` job checks the manifest, icons and `ngsw.json` of the production build. `src/app/ui/**` coverage stays ≥ 80 % and `src/app/state/**` ≥ 90 %. Container, nginx headers and release are Plan 07; Playwright e2e (offline reload, installability) is Plan 08.

**Architecture:** The lint-enforced layer rule (ADR-0002) decides where each part lives:
- `platform/pwa.ts`: `PwaPort` (abstract class, DI token) and `BrowserPwa`, the only code that touches `SwUpdate`, `beforeinstallprompt`, Cache Storage and `location.reload()`. `providePlatform()` also registers the worker (`provideServiceWorker`, production builds only). `FakePwa` joins `createFakePlatform()`.
- `state/pwa.store.ts`: `PwaStore` reads the port, `StatsStore.played()` and `SettingsStore.installDismissedAt()` and exposes `notice` (`'update' | 'offline' | 'install' | null`) plus the intents `reload()` (saves the game first), `dismiss()`, `install()` and `notNow()`. It also checks for an update when the page comes back from the background and reloads on an unrecoverable worker. `app.config.ts` creates it at start.
- `ui/screens/pwa-notice.ts`: `PwaNotice` renders the notice with Plan 05's `Toast` in the Game screen, in the flow above the board area. ui talks to the PWA only through `PwaStore`.
- Two small changes underneath: `ClockPort.epochMs()` (wall-clock time for the 30 days) and `bb:v1:settings.installDismissedAt`.
- Build side: `public/manifest.webmanifest`, `public/icons/*.png` (drawn by `scripts/make-icons.mjs`), `ngsw-config.json`, `angular.json` `serviceWorker`, `index.html` links and `scripts/check-pwa.mjs` in CI.

**Tech Stack:** Angular 22.2 standalone components and signals, `@angular/service-worker` 22.2 (`provideServiceWorker`, `SwUpdate.versionUpdates` / `unrecoverable` / `checkForUpdate()`), `provideAppInitializer`, native `animate.leave`; RxJS only inside `BrowserPwa` (to subscribe to `SwUpdate`); Cache Storage and `fetch` for the first-cache check; Node 24 built-ins (`zlib.crc32`, `deflateSync`) for the icon script; Vitest 5 via `ng test` with `@testing-library/angular` 19 on jsdom; Playwright (pre-installed Chromium) plus the Chrome DevTools Protocol (`Page.getInstallabilityErrors`) for the browser check.

**Spec:** [2026-09-27-bubble-breaker-rewrite-design.md](../specs/2026-09-27-bubble-breaker-rewrite-design.md) (milestone 6) · notices and motion in [02-ux.md](../../02-ux.md#pwa-notices) and the [design handoff](../../design/README.md) (`Bubble Breaker Screens` C1–C3, `Game Screen`, `Component Sheet` "toast / notice", `Handoff` "PWA") · ports in [03-architecture.md](../../03-architecture.md#platform-ports) · gates in [04-quality.md](../../04-quality.md#gates) · requirements in [06-deployment.md](../../06-deployment.md#pwa-deployment-requirements) · [ADR-0002](../../adr/0002-layered-architecture.md) · [ADR-0005](../../adr/0005-persistence-schema.md) · [ADR-0007](../../adr/0007-pwa-ngsw.md) · [ADR-0008](../../adr/0008-english-only-central-strings.md)

## Global Constraints

- Plans 01–05 are merged. Use the real APIs:
  - `GameStore` (`src/app/state/game.store.ts`): `save()` writes `bb:v1:game` from the final `Game` (it does nothing once the game is over); `paused()` is true for a restored game whose timer had started and after the page was hidden (only after the first selecting tap); `tap(cell)`.
  - `StatsStore`: `played()`, `recordFinished(gameId, score, timeMs)`. `SettingsStore`: `breakerSet`, `shapeHints`, `sound` and `setBreakerSet`, `setShapeHints`, `setSound`; every setter persists `bb:v1:settings` through a private `update(change)`.
  - `persistence.ts`: `KEYS`, `Settings`, `DEFAULT_SETTINGS`, `isSettings`, `loadSettings`, `saveSettings`, `DEFAULT_STATS`; `isDuration` (finite, ≥ 0) is module-private. Guards fall back to defaults and never throw (ADR-0005).
  - Ports are abstract classes used as DI tokens. `ClockPort`: `now()` (monotonic, `performance.now()`), `setTimeout`, `clearTimeout`. `VisibilityPort.hidden`. `providePlatform()` (`platform/provide-platform.ts`) returns the browser bindings and is used in `app.config.ts`.
  - Test helpers: `createFakePlatform()` (`platform/testing/fakes.ts`: `clock`, `storage`, `audio`, `visibility`, `motion`, `providers`); `FakeClock.advance(ms)` fires due timers, `pending` counts open ones; `recordFrom(bottomRows, overrides)` (`state/testing/records.ts`).
  - `Toast` (`ui/chrome/toast.ts`, `bb-toast`, host `role="status"`): inputs `heading`, `detail`, `actionLabel`, `dismissible`; outputs `act`, `dismiss`; enters with `--bb-dur-toast` / `--bb-ease-toast` (0 ms under reduced motion).
  - `GameScreen` (`ui/screens/game-screen.*`): `<bb-status-strip />`, then `.stage` (flex column) with `<bb-board-area [attr.inert]>` and the Paused dialog (absolute, `--bb-z-paused`). `BoardArea` sizes the board from its own content box with a ResizeObserver, so anything placed above it in the flow takes its height from the board area.
  - The board live region is also `role="status"`: specs that render the whole Game screen find a notice by its text, not by role.
  - `public/favicon.ico` is a 32 × 32 blue ball (a PNG); the production build lands in `dist/bubble-breaker/browser`; `.github/workflows/ci.yml` job `build` runs `npm ci` and `npm run build`.
- Layers: `platform` may import `@angular/core`, `@angular/service-worker` and `rxjs`, never `state`/`ui`. `state` imports `engine`, `platform` ports and `strings.ts`. Production files under `src/app/ui/` import `state`, `strings.ts`, other `ui` files and engine types only, never `platform`; ui specs may use the platform fakes.
- Components: standalone, `ChangeDetectionStrategy.OnPush`, selector prefix `bb-`, signal `input()`/`output()`, `inject()`. Outputs must not use DOM event names (`@angular-eslint/no-output-native`). All copy lives in `src/app/strings.ts` (ADR-0008); new blocks go just before `board: {`.
- Do not edit `src/styles/tokens.css`. The notice uses `--bb-tip`, `--bb-z-toast` (10, below `--bb-z-paused` 20), `--bb-space-*`, `--bb-dur-toast`, `--bb-ease-toast`.
- The service worker is **off** under `isDevMode()`: `ng serve` and `ng test` never register it. Real worker behaviour needs a production build served over `http://localhost` or HTTPS (Task 8). ngsw caches the app at once on `localhost` but in an idle task elsewhere, so a localhost check proves the flow, not the production timing.
- jsdom has no `navigator.serviceWorker`, no `caches`, no `beforeinstallprompt` and cannot `location.reload()`. `BrowserPwa` is tested with fakes of `SwUpdate` and of the page (`PwaHost`); `browserPwaHost(window)` is only smoke-tested.
- Coverage: `src/app/ui/**` ≥ 80 %, `src/app/state/**` ≥ 90 %, `src/app/engine/**` ≥ 95 %, overall ≥ 80 % (lines, statements, functions, branches), from `vitest-base.config.mts`; do not lower them. Lint bans `any`, non-null assertions outside specs and `testing/`, default exports and `console.*` other than `warn`/`error`; `@typescript-eslint/unbound-method` and `no-confusing-void-expression` apply to specs too.
- `scripts/*.mjs` are plain Node ESM with no dependencies; Prettier checks them (`npm run format:check` covers `.`), ESLint parses them with no rules.

## Decisions this plan makes

The docs leave these points open or disagree. Task 9 writes them back into `02-ux.md`, `03-architecture.md`, `04-quality.md`, `05-cicd.md`, `06-deployment.md` and the spec; Task 3 amends ADR-0007.

| Topic | Decision | Why |
|---|---|---|
| Dependency | `@angular/service-worker` (^22.2, same release train as `@angular/core`) is the only new runtime dependency. ADR-0007 already chose it; Task 3 amends ADR-0007 with the package, the registration and the measured bundle cost (initial 284.2 → 307.6 kB raw, 76.8 → 82.4 kB transfer) instead of adding a new ADR number | DoD item 5 needs an ADR for a new runtime dependency; the decision exists, its implementation facts were missing |
| Who saves before a reload | `PwaPort.reload()` only reloads. `PwaStore.reload()` (state) calls `GameStore.save()` and then the port | 03-architecture says the port's `reload()` "saves the game first (`GameStore.save()`)", but platform may not import state (ADR-0002) |
| Registration | `provideServiceWorker('ngsw-worker.js', { enabled: !isDevMode(), registrationStrategy: 'registerWhenStable:30000' })` inside `providePlatform()`, which now returns `(Provider \| EnvironmentProviders)[]` | One place binds the browser; tests and `ng serve` stay worker-free; Angular's default strategy registers once the app is stable (at most after 30 s), so the worker never competes with the first render |
| "Offline ready" | Shown once on a page the worker did **not** control at load (a first visit), when every URL of the `prefetch` asset groups in `ngsw.json` is in Cache Storage (`caches.match(url, { ignoreVary: true })`). Checked at start and then every 2 s for up to 2 minutes; no flag is stored | ngsw sends no event when a first install has cached the app; `checkForUpdate()` resolves before that on non-localhost hosts, because ngsw caches in an idle task after activation. A hard reload (which bypasses the worker) may show it again; harmless |
| New version | A `VERSION_READY` from `SwUpdate.versionUpdates` shows "New version available. Reload to update. Your game and statistics are kept." with **Reload** and ×. × hides it until the next load (which runs the new version anyway). Reload = `GameStore.save()` + `location.reload()`, no `activateUpdate()` | The prototype shows Reload only; without × the desktop board would stay smaller for the whole session (next row). ngsw serves the newest version to every new navigation. The game is saved too, so the copy says so |
| Update checks | `PwaStore` calls `PwaPort.checkForUpdate()` whenever the page turns visible again | An installed PWA can sit in the background for days; ngsw itself only checks on navigation and worker start |
| Unrecoverable | `SwUpdate.unrecoverable` → save, then reload, without asking | 03-architecture "Error handling" |
| Where the notice sits | In the flow of the Game screen's `.stage`, above `bb-board-area`, 8 px from the strip and 6 px from the sides (prototype). The board area measures what is left: on a portrait phone the cell does not change (360 × 640 keeps 32 px); where there is no free space above the bottom-aligned board (desktop 536 × 668 window, landscape phones) the cell shrinks while the notice shows (desktop 48 → 43 px) | 02-ux and Screens C: "never over balls". The desktop window has 0 px above the board (Plan 05), so an overlay would cover the top row |
| One at a time | `PwaStore.notice`: New version, else Offline ready, else Install. Notices show on the Game screen only. While Paused the notice is `inert` and under the Paused scrim (`--bb-z-toast` 10 < `--bb-z-paused` 20) | Screens C shows one notice at a time; the token order already puts notices below Paused |
| Install | Shown when the browser offered a prompt (`beforeinstallprompt`, kept with `preventDefault()`), `StatsStore.played() > 0`, and "Not now" is not within 30 days. **Install** opens the browser prompt; declining it there counts as "Not now". `appinstalled` drops the offer. No notice without `beforeinstallprompt` (Safari, Firefox) | 02-ux and the handoff say "Not now suppresses for 30 days"; Screens C says "offered once … never on the first visit". 30 days wins; "after the first finished game" already keeps it off a fresh first visit |
| 30 days | New `ClockPort.epochMs()` (`Date.now()`); `FakeClock.epochMs()` = `FakeClock.EPOCH` (2026-10-01T00:00:00Z) + its time | `ClockPort.now()` is monotonic from an arbitrary origin and means nothing across sessions |
| Settings schema | `bb:v1:settings` gains `installDismissedAt: number \| null` (wall-clock ms). `isSettings` accepts records without it and `loadSettings` fills in `null`; the key stays v1 | 03-architecture puts the timestamp in settings. Old records stay valid, so nobody loses their options; older app versions ignore the extra field (rollback-safe, ADR-0005) |
| Notice role and focus | All three notices are `Toast`s with `role="status"`, including Install (the prototype uses `role="dialog"`). A notice never takes focus. When a notice goes away while focus is inside it (×, Not now, Install, the 4 s auto-hide), focus goes to the board | A non-modal notice that grabbed focus would interrupt play; a polite status is announced without moving the cursor |
| Install layout | `Toast` gets `dismissLabel` (string or null): when set, the text stacks above a "Not now" button and the action becomes the default button (bold, ring), as in the Game Screen prototype | The existing inline layout has room for one action and × only |
| Leave motion | `animate.leave="toast-leave"` (Angular 22, no animations package): opacity 1 → 0 and translateY 0 → −4 px over `--bb-dur-toast` (0 ms with reduced motion) | 02-ux motion row "Toast"; the handoff's "Toast in / out". Plan 05 built the enter half |
| Manifest | `id` and `start_url` and `scope` `/`, `display: standalone`, `name` "Bubble Breaker", `short_name` "Bubbles" (≤ 12 characters, so launchers do not truncate it), `theme_color` `#0A246A` (`--bb-title-from`, as in `index.html`), `background_color` `#D4D0C8` (`--bb-face`, the touch body background), `lang: en`, `categories: ["games"]`; no `orientation` lock | 06-deployment lists the fields; 02-ux recomputes the board on rotation |
| Icons | `scripts/make-icons.mjs` (no dependency) draws the tokens.css blue-ball recipe, like the favicon: `icon-192.png` and `icon-512.png` (transparent, ball 92 %), `icon-maskable-512.png` (white full-bleed, ball 64 %, inside the 80 % safe zone), `apple-touch-icon.png` 180 px (white). The PNGs are committed; `npm run icons` redraws them byte for byte. The favicon stays | The handoff has no app icon; binaries need a reproducible source and no proprietary art (02-ux "Must not get wrong" 9) |
| ngsw config | Asset groups only: `app` (prefetch: favicon, `index.html`, manifest, `/*.css`, `/*.js`, fonts) and `icons` (lazy). Default navigation fallback to `index.html`; no data groups | ADR-0007, 06-deployment; the build leaves `ngsw-worker.js`, `safety-worker.js` and `worker-basic.min.js` out of the groups by itself |
| CI check | `scripts/check-pwa.mjs` runs in the `build` job after `npm run build` (`npm run check:pwa`): manifest fields, icon files and PNG sizes, manifest link and theme colour in `index.html`, no data groups, prefetched shell and fonts, every `ngsw.json` URL present | Installability e2e is Plan 08; until then a cheap build-time check catches a broken manifest or config |
| Browser check | Production build in `dist/pwa-check/v1`, a copy with a changed `index.html` and a regenerated `ngsw.json` (`ngsw-config` CLI) in `v2`, served by a scratch Node server that behaves like the nginx rules (SPA fallback, real 404 for missing files, `no-cache` on the worker files). `beforeinstallprompt` is dispatched by the script (headless Chromium never fires it) | The real flows need a worker; the update flow needs two versions of the same build |

```ts
import { signal, type Signal } from '@angular/core';
import type { SwUpdate } from '@angular/service-worker';
import type { ClockPort } from './clock';

/** Service worker and install prompt, seen from the page (ADR-0007). */
export abstract class PwaPort {
  /** A new version is downloaded and ready; the next page load runs it. */
  abstract readonly updateAvailable: Signal<boolean>;
  /** First visit only: the service worker has cached every app-shell file. */
  abstract readonly offlineReady: Signal<boolean>;
  /** The browser offers to install the app (a `beforeinstallprompt` was kept). */
  abstract readonly installAvailable: Signal<boolean>;
  /** The service worker can no longer serve this version; only a reload helps. */
  abstract readonly unrecoverable: Signal<boolean>;
  /** Asks the service worker to look for a new version. */
  abstract checkForUpdate(): void;
  /** Shows the browser's install prompt; resolves true when the player accepts. */
  abstract install(): Promise<boolean>;
  abstract reload(): void;
}

/** The parts of `SwUpdate` the port uses. */
export type ServiceWorkerSource = Pick<
  SwUpdate,
  'isEnabled' | 'versionUpdates' | 'unrecoverable' | 'checkForUpdate'
>;

/** `beforeinstallprompt` (Chromium only, so not in lib.dom). */
export interface InstallPromptEvent extends Event {
  prompt(): Promise<unknown>;
  readonly userChoice: Promise<{ readonly outcome: 'accepted' | 'dismissed' }>;
}

/** The page around the port; `browserPwaHost(window)` in the app. */
export interface PwaHost {
  /** A service worker controlled the page when it loaded, so this is not a first visit. */
  readonly controlled: boolean;
  addEventListener(
    type: 'beforeinstallprompt' | 'appinstalled',
    listener: (event: Event) => void,
  ): void;
  /** True once every file the service worker prefetches is in Cache Storage. */
  appShellCached(): Promise<boolean>;
  reload(): void;
}

/** How often, and how long, a first visit looks for the finished app-shell cache (2 min). */
const CACHE_POLL_MS = 2_000;
const CACHE_POLL_TRIES = 60;

export class BrowserPwa extends PwaPort {
  private readonly update = signal(false);
  private readonly offline = signal(false);
  private readonly installable = signal(false);
  private readonly broken = signal(false);
  private prompt: InstallPromptEvent | null = null;

  readonly updateAvailable = this.update.asReadonly();
  readonly offlineReady = this.offline.asReadonly();
  readonly installAvailable = this.installable.asReadonly();
  readonly unrecoverable = this.broken.asReadonly();

  constructor(
    private readonly sw: ServiceWorkerSource,
    private readonly host: PwaHost,
    private readonly clock: ClockPort,
  ) {
    super();
    if (sw.isEnabled) {
      sw.versionUpdates.subscribe((event) => {
        if (event.type === 'VERSION_READY') {
          this.update.set(true);
        }
      });
      sw.unrecoverable.subscribe(() => {
        this.broken.set(true);
      });
      if (!host.controlled) {
        this.watchFirstCache(CACHE_POLL_TRIES);
      }
    }
    // Keep the prompt for the install notice instead of the browser's own mini-infobar.
    host.addEventListener('beforeinstallprompt', (event) => {
      event.preventDefault();
      this.prompt = event as InstallPromptEvent;
      this.installable.set(true);
    });
    host.addEventListener('appinstalled', () => {
      this.prompt = null;
      this.installable.set(false);
    });
  }

  checkForUpdate(): void {
    if (this.sw.isEnabled) {
      this.sw.checkForUpdate().catch((error: unknown) => {
        console.warn('Update check failed', error);
      });
    }
  }

  async install(): Promise<boolean> {
    const prompt = this.prompt;
    if (prompt === null) {
      return false;
    }
    // A prompt can be shown only once.
    this.prompt = null;
    this.installable.set(false);
    await prompt.prompt();
    const { outcome } = await prompt.userChoice;
    return outcome === 'accepted';
  }

  reload(): void {
    this.host.reload();
  }

  /**
   * ngsw sends no event when a first install has cached the app (and caches in an idle task
   * after activation), so a first visit checks Cache Storage until the app shell is complete.
   */
  private watchFirstCache(triesLeft: number): void {
    void this.host.appShellCached().then((cached) => {
      if (cached) {
        this.offline.set(true);
      } else if (triesLeft > 1) {
        this.clock.setTimeout(() => {
          this.watchFirstCache(triesLeft - 1);
        }, CACHE_POLL_MS);
      }
    });
  }
}

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value);
}

/** The URLs of the `prefetch` asset groups in an `ngsw.json` manifest. */
function prefetchUrls(manifest: unknown): string[] {
  const groups = isRecord(manifest) ? manifest['assetGroups'] : undefined;
  if (!Array.isArray(groups)) {
    return [];
  }
  return groups.flatMap((group: unknown) =>
    isRecord(group) && group['installMode'] === 'prefetch' && Array.isArray(group['urls'])
      ? group['urls'].filter((url: unknown): url is string => typeof url === 'string')
      : [],
  );
}

/** Whether every app-shell file listed in `ngsw.json` is in Cache Storage. Never throws. */
export async function appShellCached(
  fetchFn: typeof fetch,
  cacheStorage: Pick<CacheStorage, 'match'>,
): Promise<boolean> {
  try {
    const response = await fetchFn('ngsw.json', { cache: 'no-store' });
    if (!response.ok) {
      return false;
    }
    const urls = prefetchUrls(await response.json());
    // ngsw stores its asset groups with `ignoreVary`.
    const hits = await Promise.all(
      urls.map((url) => cacheStorage.match(url, { ignoreVary: true })),
    );
    return urls.length > 0 && hits.every((hit) => hit !== undefined);
  } catch {
    return false;
  }
}

export function browserPwaHost(win: Window): PwaHost {
  return {
    controlled: 'serviceWorker' in win.navigator && win.navigator.serviceWorker.controller !== null,
    addEventListener: (type, listener) => {
      win.addEventListener(type, listener);
    },
    appShellCached: () =>
      'caches' in win ? appShellCached(win.fetch.bind(win), win.caches) : Promise.resolve(false),
    reload: () => {
      win.location.reload();
    },
  };
}
```

```ts
import { computed, effect, inject, Injectable, signal, untracked } from '@angular/core';
import { ClockPort, type TimerId } from '../platform/clock';
import { PwaPort } from '../platform/pwa';
import { VisibilityPort } from '../platform/visibility';
import { GameStore } from './game.store';
import { SettingsStore } from './settings.store';
import { StatsStore } from './stats.store';

/** The PWA notices at the top of the board area (02-ux "PWA notices"). */
export type PwaNotice = 'update' | 'offline' | 'install';

/** "Offline ready" hides itself after 4 s. */
export const OFFLINE_NOTICE_MS = 4_000;
/** "Not now" keeps the install notice away for 30 days. */
export const INSTALL_SNOOZE_MS = 30 * 24 * 60 * 60 * 1_000;

/**
 * Decides which PWA notice shows, one at a time and most urgent first: a new version, then
 * offline ready, then the install offer. Saves the game before every reload.
 */
@Injectable({ providedIn: 'root' })
export class PwaStore {
  private readonly pwa = inject(PwaPort);
  private readonly game = inject(GameStore);
  private readonly stats = inject(StatsStore);
  private readonly settings = inject(SettingsStore);
  private readonly clock = inject(ClockPort);
  private readonly visibility = inject(VisibilityPort);
  private readonly updateDismissed = signal(false);
  private readonly offlineShowing = signal(false);
  private offlineTimer: TimerId | null = null;

  /** Only after a finished game, and not within 30 days of "Not now". */
  private readonly installDue = computed(() => {
    const dismissedAt = this.settings.installDismissedAt();
    return (
      this.pwa.installAvailable() &&
      this.stats.played() > 0 &&
      (dismissedAt === null || this.clock.epochMs() - dismissedAt >= INSTALL_SNOOZE_MS)
    );
  });

  readonly notice = computed<PwaNotice | null>(() => {
    if (this.pwa.updateAvailable() && !this.updateDismissed()) {
      return 'update';
    }
    if (this.offlineShowing()) {
      return 'offline';
    }
    return this.installDue() ? 'install' : null;
  });

  constructor() {
    effect(() => {
      if (this.pwa.offlineReady()) {
        untracked(() => {
          this.showOffline();
        });
      }
    });
    effect(() => {
      if (this.pwa.unrecoverable()) {
        untracked(() => {
          this.reload();
        });
      }
    });
    // A PWA can sit in the background for days: look for a new version when it comes back.
    let wasHidden = this.visibility.hidden();
    effect(() => {
      const hidden = this.visibility.hidden();
      if (wasHidden && !hidden) {
        untracked(() => {
          this.pwa.checkForUpdate();
        });
      }
      wasHidden = hidden;
    });
  }

  /** Reload on "New version" (and after an unrecoverable state): the game is saved first. */
  reload(): void {
    this.game.save();
    this.pwa.reload();
  }

  /** × on "New version" (until the next load) or on "Offline ready". */
  dismiss(): void {
    if (this.notice() === 'update') {
      this.updateDismissed.set(true);
    } else {
      this.hideOffline();
    }
  }

  /** Install: the browser's prompt. Declining it there counts as "Not now". */
  install(): void {
    void this.pwa.install().then((accepted) => {
      if (!accepted) {
        this.notNow();
      }
    });
  }

  notNow(): void {
    this.settings.setInstallDismissedAt(this.clock.epochMs());
  }

  /** The port reports offline ready at most once per page load. */
  private showOffline(): void {
    this.offlineShowing.set(true);
    this.offlineTimer = this.clock.setTimeout(() => {
      this.hideOffline();
    }, OFFLINE_NOTICE_MS);
  }

  private hideOffline(): void {
    if (this.offlineTimer !== null) {
      this.clock.clearTimeout(this.offlineTimer);
      this.offlineTimer = null;
    }
    this.offlineShowing.set(false);
  }
}
```

```ts
 * ready or Install, one at a time. It takes its height from the board area, so it never
 * covers a ball. A notice that goes away while it has focus hands focus back to the board.

  templateUrl: './pwa-notice.html',

export class PwaNotice {
  /** The focused notice went away; the board should take focus. */
  readonly handBack = output();

      untracked(() => {
        if (this.host.nativeElement.contains(this.document.activeElement)) {

  }
```

```js
// Draws the app icons into public/icons/: one blue ball with the tokens.css recipe (base
// gradient + specular), like the favicon. No dependencies: Node's zlib writes the PNGs.
// Run `npm run icons` after changing this file and commit the PNGs.
import { mkdirSync, writeFileSync } from 'node:fs';
import { crc32, deflateSync } from 'node:zlib';

const OUT = new URL('../public/icons/', import.meta.url);

/** tokens.css: --bb-blue-hi, --bb-blue, --bb-blue-edge. */
const HI = [0x50, 0x64, 0xff];
const BODY = [0x14, 0x14, 0xd2];
const EDGE = [0x00, 0x00, 0x5a];
const WHITE = [0xff, 0xff, 0xff];

/** `background` null = transparent; `ball` = ball diameter / icon size. */
const ICONS = [
  { file: 'icon-192.png', size: 192, ball: 0.92, background: null },
  { file: 'icon-512.png', size: 512, ball: 0.92, background: null },
  // Maskable: full-bleed board white, ball inside the 80 % safe zone.
  { file: 'icon-maskable-512.png', size: 512, ball: 0.64, background: WHITE },
  // iOS fills transparency with black.
  { file: 'apple-touch-icon.png', size: 180, ball: 0.8, background: WHITE },
];

const mix = (a, b, t) => a.map((v, i) => v + (b[i] - v) * t);

/** radial-gradient(circle farthest-side at 35% 30%, hi 0%, body 40%, edge 100%). */
function base(x, y) {
  const t = Math.min(Math.hypot(x - 0.35, y - 0.3) / 0.7, 1);
  return t < 0.4 ? mix(HI, BODY, t / 0.4) : mix(BODY, EDGE, (t - 0.4) / 0.6);
}

/** --bb-specular: white at 30% 28%, alpha .95 → .55 at 5 % → 0 at 11 % of the corner distance. */
function specular(x, y) {
  const t = Math.hypot(x - 0.3, y - 0.28) / Math.hypot(0.7, 0.72);
  if (t >= 0.11) {
    return 0;
  }
  return t < 0.05 ? 0.95 - (0.4 * t) / 0.05 : 0.55 * (1 - (t - 0.05) / 0.06);
}

/** RGBA pixels, 4 × 4 samples per pixel for smooth edges. */
function draw({ size, ball, background }) {
  const pixels = Buffer.alloc(size * size * 4);
  const diameter = size * ball;
  const offset = (size - diameter) / 2;
  const samples = 4;
  for (let py = 0; py < size; py++) {
    for (let px = 0; px < size; px++) {
      let r = 0;
      let g = 0;
      let b = 0;
      let a = 0;
      for (let sy = 0; sy < samples; sy++) {
        for (let sx = 0; sx < samples; sx++) {
          // Position inside the ball's box, 0…1.
          const x = (px + (sx + 0.5) / samples - offset) / diameter;
          const y = (py + (sy + 0.5) / samples - offset) / diameter;
          let color = background;
          if (Math.hypot(x - 0.5, y - 0.5) <= 0.5) {
            color = mix(base(x, y), WHITE, specular(x, y));
          }
          if (color !== null) {
            r += color[0];
            g += color[1];
            b += color[2];
            a += 1;
          }
        }
      }
      const i = (py * size + px) * 4;
      if (a > 0) {
        pixels[i] = Math.round(r / a);
        pixels[i + 1] = Math.round(g / a);
        pixels[i + 2] = Math.round(b / a);
      }
      pixels[i + 3] = Math.round((255 * a) / (samples * samples));
    }
  }
  return pixels;
}

function chunk(type, data) {
  const head = Buffer.alloc(8);
  head.writeUInt32BE(data.length, 0);
  head.write(type, 4, 'latin1');
  const crc = Buffer.alloc(4);
  crc.writeUInt32BE(crc32(Buffer.concat([head.subarray(4), data])), 0);
  return Buffer.concat([head, data, crc]);
}

function png(size, pixels) {
  const header = Buffer.alloc(13);
  header.writeUInt32BE(size, 0);
  header.writeUInt32BE(size, 4);
  header[8] = 8; // bit depth
  header[9] = 6; // RGBA
  const rows = Buffer.alloc(size * (size * 4 + 1));
  for (let y = 0; y < size; y++) {
    // Filter byte 0 (none), then the row.
    pixels.copy(rows, y * (size * 4 + 1) + 1, y * size * 4, (y + 1) * size * 4);
  }
  return Buffer.concat([
    Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]),
    chunk('IHDR', header),
    chunk('IDAT', deflateSync(rows, { level: 9 })),
    chunk('IEND', Buffer.alloc(0)),
  ]);
}

mkdirSync(OUT, { recursive: true });
for (const icon of ICONS) {
  const data = png(icon.size, draw(icon));
  writeFileSync(new URL(icon.file, OUT), data);
  console.log(
    `${icon.file} ${String(icon.size)}×${String(icon.size)} ${String(data.length)} bytes`,
  );
}
```
