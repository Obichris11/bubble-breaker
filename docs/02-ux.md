## Visual direction

- Retro Windows Mobile / Pocket PC chrome: `#D4D0C8` face, 2-px bevels, navy gradient title bar, square corners.
- Pure white board, no grid lines. Glossy balls drawn with two radial gradients (`farthest-side` is required).
- Font: Noto Sans (OFL), **self-hosted** for offline use. No Microsoft fonts, logos or assets.
- **No dark theme** (a dark board breaks the sphere shading). Desktop shows the app window on a `#2F6468` backdrop.

## Screen layout

Vertical column: title bar 26 px → status strip 30 px (Score · Selected · Time) → board area (flex 1) → softkey bar (44 px touch / 32 px `pointer: fine`). Only the board scales.

```
avail_w = viewport_w − 2 × 4
avail_h = viewport_h − 26 − 30 − softkey_h − 4 − safe-area insets
cell    = floor(min(avail_w / 11, avail_h / 12, cell_max))   // cell_max 72 touch, 48 desktop
board   = 11·cell × 12·cell, centered horizontally, bottom-aligned
```

| Viewport | Cell | Board |
|---|---|---|
| 360×640 | 32 px | 352×384 |
| 390×844 | 34 px | 374×408 |
| 768×1024 | 69 px | 759×828 |
| Desktop | 48 px | app window 536×692; recompute from height if viewport < 700 px tall |

Integer cells only. `100dvh`, `env(safe-area-inset-*)`, ResizeObserver on the board area. Board is bottom-aligned: the free space above holds PWA notices.

## Interaction

- One pointer handler on the board: `col = floor(x / cell)`, `row = floor(y / cell)`. Whole cell is the hit area. `touch-action: manipulation`.
- States per rules R8/R9: tap group → select + points bubble; tap same group → burst; other group → move selection; lone ball / empty / outside → clear.
- Input ignored during pop, fall, slide.
- Burst sequence: pop → gravity (all columns at once) → slide columns right → game-over check → 500 ms → Scoring.
- Points bubble: above tapped ball (below if top row), center clamped 34 px from board edges, `pointer-events: none`. "Selected" status field mirrors the value.
- Timer pauses while menu/screen/dialog is open and when the page is hidden. `visibilitychange → hidden` ⇒ Paused state.
- **Persistence:** save board + elapsed time on every burst and on pause → the game in progress survives reload.

## Motion

Animate `transform` / `opacity` only. Each ball is an absolutely positioned element keyed by stable id, placed with `translate(col·cell, row·cell)`. Ball nodes are never re-created between phases.

| Event | Animation | Duration | Easing | Reduced motion |
|---|---|---|---|---|
| Select | Highlight + bubble fade in | 80 ms | `cubic-bezier(.2,0,0,1)` | Instant |
| Move/clear selection | Swap instantly | 0 | – | Same |
| Burst | scale 1→0.2, opacity 1→0 | 160 ms | `cubic-bezier(.4,0,1,1)` | Opacity 80 ms linear |
| Fall | translateY, all columns together | 240 ms | `cubic-bezier(.55,0,1,.45)` | Jump |
| Slide right | translateX, after fall | 200 ms | `cubic-bezier(.2,0,0,1)` | Jump |
| Game over | Hold board, open Scoring | 500 ms delay | – | No delay |
| Toast | opacity + translateY −4→0 | 150 ms | `cubic-bezier(.2,0,0,1)` | Instant |
| Menu, dialog, new game | Instant | 0 | – | Same |

## Accessibility (WCAG 2.2 AA)

- **Keyboard:** board is one focusable element (`tabindex="0"`) with its own cursor. Arrows move (onto empty cells too, no wrap); Enter/Space select then burst; Esc clears or closes menu; **N** new game; **M** menu. Board focus ring 2 px black + 1 px white keylines, keyboard-only (`:focus-visible`). Chrome buttons: 1 px dotted focus rect. Menus: arrows, Home/End, Esc, return focus to Menu softkey. Dialogs trap focus, start on Cancel, close on Esc.
- **Screen readers:** board `role="application"` with key-help `aria-label`; polite live region announces cursor cell, selection, burst result, game over.
- **Not color only:** selection = 3:1 cell background + bubble + live region. Greyscale set: diagonal, solid, dotted, banded, checkered + lightness. Optional shape hints ▲ ● ■ ◆ ✚ on Colorful.
- **Contrast:** verified in handoff §4 (all text ≥ 4.5:1, UI ≥ 3:1).
- **Targets:** softkeys/buttons/option rows ≥ 44 px on touch; menu rows 40 px (≥ 24 px per 2.5.8).

## PWA notices

Shown at the top of the board area (never over balls):
- **New version available** → Reload (save game first; reload only on tap).
- **Offline ready** → once, after first cache, auto-hide 4 s.
- **Install** → only after the first finished game and when `beforeinstallprompt` is available; "Not now" suppresses for 30 days.

## Sound

Option on/off (in Options). Reuse the legacy synthesized sounds (select, pop, game over); create/resume the AudioContext on the first user gesture. Sound design detail to be refined in implementation.

## Must not get wrong (from handoff §7)

1. Empty columns close to the **right**.
2. 4-neighbour adjacency; a single ball is never a group.
3. Score `n × (n − 1)`; no end bonus; time not scored.
4. Idle ball rendering never changes for highlight/focus/burst — cues go behind or around it.
5. No outlines, shadows or reflections on balls; no grid lines; board `#FFFFFF`.
6. Stable ball DOM nodes (track by id); move with `transform`, never `top/left`.
7. Game over opens Scoring automatically; finished game added to stats **exactly once**.
8. Integer cell sizes; recompute on resize/orientation change.
9. No proprietary fonts or logos; self-host Noto Sans.

## Additions to the ruleset (feed back into architecture)

- Game-in-progress persistence (board, score, elapsed, seed).
- Stats gain **Last Game** (score + time).
- Options: Breaker Set, shape hints, sound — persisted.
- Shortcuts N / M.
